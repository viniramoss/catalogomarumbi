# Catálogo de preços Marumbi

Catálogo de preços das unidades do Açougue Marumbi, em Curitiba: um site para cada unidade, com nome e preço/kg dos produtos, ligados ao GranMoney.

- Marumbi 1 (Uberaba): https://catalogomarumbiuberaba.vercel.app
- Marumbi 3 (Capão da Imbuia): https://catalogomarumbiimbuia.vercel.app

Como mexer, testar e publicar: [MAINTENANCE_GUIDE.md](MAINTENANCE_GUIDE.md).

O site original da Casa de Carnes Marumbi (https://casadecarnesmarumbi.vercel.app) fica em outro repositório, [viniramoss/casadecarnesmarumbi](https://github.com/viniramoss/casadecarnesmarumbi), e não muda com este.
